# Free sample — AI Interview Lab

A complete permission-aware retrieval exercise: broken starter, eight checks, staged hints, reference fix and explanation rubric. Original simulation; not a company interview question. Python 3.10+, no dependency installation or API key.

Unzip, open a terminal in the extracted folder, then run:

```sh
python3 practice.py retrieval
```

The starter deliberately fails. Read `docs/01-retrieval.md`, edit `exercises/retrieval.py`, rerun, then compare with `python3 practice.py retrieval --reference`. Save a local progress report using `--report attempt-1.json`; existing files are not overwritten. Code runs locally; no upload or remote grading. Do not treat test count as hiring readiness.

The complete edition adds evaluation accounting and budget-reservation labs, with full explanations and references. Planned price US$19 once; checkout is not open. Try this sample before considering the full pack. License: SAMPLE-LICENSE.txt.
