# Free sample — AI Interview Lab

A complete permission-aware retrieval exercise: broken starter, eight checks, staged hints, reference fix and explanation rubric. Original simulation; not a company interview question. Python 3.10+, no dependency installation or API key.

Unzip, open a terminal in the extracted folder, then run:

```sh
python3 practice.py retrieval
```

The starter deliberately fails. Read `docs/01-retrieval.md`, edit `exercises/retrieval.py`, rerun, then compare with `python3 practice.py retrieval --reference`.
